# Claude Code 版 v2.26.0 の反映

## 対象

移植元の `v2.25.0..v2.26.0` を、Codex 版 `v1.20.0` と比較した。移植元の終点は `82d6895`、移植先の基点は `002f4b6` である。

| 移植元 | Codex 版の対応 |
|---|---|
| `rules/working-principles.md` | 目的と理由を明示する文の書き方、転記時の確認、強調記号と補足の丸かっこの扱いを共通ルールへ追加した。Claude Code 固有のツールやセッションの記述は移植対象から外した |
| `rules/documentation.md` | 強調記号と補足の丸かっこの規則を日本語技術文書スキルから参照した。強調の助詞「まで」は既存の規則で扱う |
| `rules/testing.md` | テストを通すためだけに実装やテスト機構を変えることを禁じる規則を共通ルールへ追加した |
| `rules/beads.md` と `rules/project.md` | 文体上の差分を確認した。Codex 用の Beads 統合、コマンドの承認、計画の反証には既存の規則を適用する |
| `skills/software-test/SKILL.md` | テストの範囲、権限境界、フィクスチャ、ランナー移行の規則を移植した。Codex の検出に必要な `name` を追加し、権限のテストをリクエストの入口で実行する表現にした |
| `skills/technical-blog-writing/SKILL.md` | 冒頭の結論を太字にする指定を削除した |
| `README.md` | 装飾による強調を外し、導入する 4 つのスキルと更新履歴を記載した |

Windows 版では既存のスキルと同じコピー方式を使う。管理記録のハッシュで上書きと解除の対象を判定し、失敗時は導入直前の状態へ戻す。macOS 版では既存のスキルと同じ方式でシンボリックリンクを作成する。

この PC の旧 `software-test` からは、権限を緩める変更で残すべき制限のレビューを維持した。未知の権限の扱いは認可実装の方針に属するため、配布するテストスキルの対象から外した。旧スキルは適用時に Codex の検出範囲外へ退避する。

## 検証

- Windows で `tests/run.ps1` の 51 件と `scripts/verify-beads.ps1` の隔離統合検証が成功した。導入、再実行、通常解除、完全復元、再導入を確認した。
- Windows の追加の隔離検証で、旧 state v3 からの更新、管理外の同名スキルによる停止、配置後の状態保存失敗からの復元、解除時の利用者編集の保全を確認した。
- WSL の Ubuntu で POSIX シェル版の 5 項目が成功した。LF にそろえた一時コピーで、新スキルのリンク先と内容、既存の設定保持を確認した。macOS 実機は未検証である。
- フックの既存 Python テストは WSL で 16 件成功した。PowerShell が必要な 1 件はスキップした。Windows では UTF-8 モードで実行しても、既存テストのパス区切りの期待値とシンボリックリンク作成権限で各 1 件が失敗した。今回の差分にフック本体と Python テストの変更は含まれない。
- 新規・更新した 3 つのスキルは Codex の `quick_validate.py` で検証した。
